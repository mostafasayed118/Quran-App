## Derived copy

`arcade.jpg` is a 1600×956 re-encode of that file at JPEG quality 78 (318 KB). The page renders
it under `filter: saturate(.46) brightness(.64) contrast(1.05) sepia(.26) blur(2px)` with a scrim,
so the stored resolution is deliberate: a 2× display gets a soft image by design, not a shortage.

CC0 asks for no credit; the author is credited here and in a comment in
`src/styles/heritage.css` anyway. Any replacement image must clear the same bar — a licence
verified against the source metadata, not inferred from a filename — before it ships.
