# Quran Yahdi Web — P3 "Official Site" — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Execute this plan task-by-task (subagent-driven-development recommended: one fresh subagent per task, review between tasks). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the P3 official-site program: full landing, `/about`, `/privacy` (single-source from repo `PRIVACY.md` + EN mirror), EN mirrors for every route (`/en/**`, LTR), a real localized 404, SEO basics (sitemap/hreflang/OG), and download CTAs — closing with gates + Lighthouse ≥90 mobile.

**Architecture:** Keep the static-Astro + locked-token-CSS architecture untouched. Add EN as a path-prefixed locale (`/en/**`; astro.config i18n already sets `prefixDefaultLocale: false`). Legal pages import the repo-root markdown directly (single source). The sitemap is a dependency-free static endpoint.

**Tech Stack:** Astro 7 (static) · TypeScript strict (`astro check`) · token CSS only (Tailwind was dropped in WEB-POLISH-1 — never re-add) · Vitest · Playwright (chromium) · Node ≥22 (build scripts) · Cloudflare Pages.

- **Web-only.** Allowed paths are exactly those listed per task under `web/**`, plus `PRIVACY.en.md` (new, repo root) and docs listed per task. NEVER touch: app code (`lib/`, `android/`, `ios/`, `test/`), `INSTRUCTIONS.md`, `.vscode/settings.json`, other features.
- **Commits**: English messages, byte-copied verbatim from this plan (do NOT translate). Explicit pathspecs only. Never `git add -A`, never stash/reset.
- **NO PUSH.** Executors never push; the window belongs to the owner.
- **Gates**: per commit run `npm run check` + the affected test files; on the final tip run the FULL `npm run gates` + `npm run test:e2e`. Budget must stay PASS — at plan time: reader JS **24.35 KB / 30 KB** gzip; dist **145 / 2000** files (EN mirrors will grow the dist count — keep it <2000).
- **Strings**: every new UI string key is added to BOTH dictionaries in `web/src/lib/strings.ts` (AR + EN, symmetric); the parity test stays green. Bold content (hero/features/about) lives in `web/src/lib/landing-content.ts` (both locales together + a structural-parity unit test) — NOT in strings.ts.
- **Design**: tokens only (`var(--…)` from `web/src/styles/tokens.css`); no raw colors/spacings outside tokens (contrast test enforces); re-use existing patterns (`.rc-btn`, `.page-title`, `.empty`, `@media (pointer: coarse)` 44px rules).

- **Locale**: `ar` = default at `/` (`lang="ar" dir="rtl"`); `en` = mirrored at `/en/**` (`lang="en" dir="ltr"`). BaseLayout already computes `dir` from the `locale` prop.
- **No new dependencies.** Sitemap = static endpoint; legal = direct markdown import; Lighthouse = one-off tooling, never a repo dep.
